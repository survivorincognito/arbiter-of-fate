# The Fate Director — v2.0 Release Notes

**Release identity:** The Arbiter of Fate. The product remains **Skyrim — The Fate Director**.

## Included in v2.0

- Curated Skyrim quest catalogue, faction tracking, Quest Journal with filters, discover/complete/block controls and assignment eligibility guidance.
- Character guide with race starting skills and selectable playstyles; Perk Focus and progression tracking.
- Spellbook with Survivor's Choice, Fate's Choice and Shared Control; learned spells and permission tracking.
- Dragon Shouts tracker with individual discovered and unlocked Words of Power.
- Expedition Chronicle, Undo, browser-local persistence, JSON backup import/export, offline operation and mobile-friendly navigation.
- Release About section, known limitations and backup guidance.
- New guiding identity **The Arbiter of Fate**. Gameplay RNG, eligibility rules and expedition storage format are unchanged from v1.9.84.

## Compatibility

Saved JSON expedition schema is still version 1; the storage key is unchanged. A previously tested Brave backup imported and survived a browser restart before v2.0 packaging. For new locations/hosts, export and import the backup to carry over progress.

## Known limitations

Some DLC/Creation quest triggers, alternate endings and spell acquisition details remain advisory and need confirmation during gameplay. Browser local storage can be location-dependent or cleared; export frequent JSON backups. The Director does not modify Skyrim itself. Unofficial fan-made software, not affiliated with Bethesda.

## Integrated user guide and navigation

- Renamed the **Director** tab to **Arbiter**; preserved its underlying tab ID and stored settings.
- Added a seven-chapter collapsible How to Use guide under Settings with shortcuts to actual controls.
- Updated the Dashboard help shortcut to open the guide.
- No quest, character, spell, shout or RNG rule changes. The v1 local-storage key and JSON backup format remain unchanged.
